# FocusGuard
Screen-time tracker + per-app daily limits (auto-lock). Kotlin + Jetpack Compose, Android 7.0+ (API 24).
Build: open this folder in Android Studio -> Build > Build APK(s). Install APK on any phone.
First launch: Setup tab -> grant Usage access and Display over other apps.
Languages: English, Bangla, Spanish (add values-xx/strings.xml for more).
